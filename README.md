# Notch Tray

Полка для файлов в чёлке Mac. Версия 0.4.12 (19), macOS 14+.

Кнопка «Сохранить» в редакторе скриншотов записывает разметку в исходный файл.
Сборка в комплекте предназначена для Apple Silicon. Интерфейс на русском.

## Запуск

Откройте «Notch Tray.app». Можно перенести приложение в «Программы».
Значок полки появится в строке меню; отдельного значка в Dock нет.
Если другое приложение уже занимает чёлку, завершите его перед тестом.
Сборка подписана постоянным локальным сертификатом; подписи Developer ID и notarization нет.
Для локального запуска не требуется платная учётная запись разработчика.

## Загрузка и обновления

Скачайте архив для Apple Silicon на [странице последнего выпуска](https://github.com/5123082-wq/notch-tray/releases/latest),
распакуйте его и перенесите приложение в «Программы». Эта сборка подписана локальным
сертификатом. При первом открытии macOS может предупредить о приложении от неизвестного разработчика.
После попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность»
и подтвердите открытие именно Notch Tray, если доверяете скачанной копии.
[Инструкция Apple по первому запуску](https://support.apple.com/ru-ru/102445)

Раз в сутки во время работы приложение запрашивает номер опубликованного выпуска на GitHub.
Если доступна новая версия, полка показывает её номер, а меню в строке macOS открывает страницу скачивания.
Там же доступны ручная проверка и переключатель автоматических проверок. Новую версию устанавливает пользователь.

## Использование

1. Перетащите файл или несколько файлов из Finder к центру верхнего края экрана.
2. Дождитесь раскрытия и отпустите файлы на полку. Зелёная рамка обозначает приём.
3. Переключитесь в нужное приложение.
4. Наведите указатель на чёлку, возьмите миниатюру и перетащите её в приложение.

⌘ + щелчок выбирает несколько файлов, Shift выбирает диапазон.
Выберите карточку и нажмите **пробел**, чтобы открыть системный «Быстрый просмотр».
Щелчок по чёлке активирует сохранённое выделение. При раскрытии наведением
рамка остаётся приглушённой, пока полка не получит клавиатурный фокус.
Стрелки **← / →** листают файлы текущего раздела, а при множественном выделении —
только выбранные карточки.
Окно целиком вписывается в свободную область экрана под раскрытой полкой,
включая большие изображения; верхние кнопки просмотра остаются доступными.
Повторный пробел или **Escape** возвращает к последней просмотренной карточке.
В окне просмотра изображения нажмите **«Редактировать»** (⌘E). Та же команда доступна
по правому щелчку на карточке в обоих разделах. В меню **«Фигуры»** выберите
**«Рамка»**, **«Круг»** или **«Линия»** и потяните по снимку. Отпустите кнопку мыши,
когда фигура достигнет нужного размера. **«Стрелка»** и **«Перо»** доступны на панели.
Наведите курсор на контур существующей пометки и потяните, чтобы её переместить.
У стрелки и линии можно тянуть любой конец. У рамки боковые точки меняют один
размер, угловые — оба. У круга потяните точку на окружности, чтобы изменить диаметр.
В пустом месте продолжает рисовать выбранный инструмент.
Щёлкните по пометке и нажмите Delete, чтобы убрать её до сохранения.
Для подписи выберите **«Текст»**, щёлкните в нужном месте снимка и начните печатать.
**Enter** начинает новую строку. Щелчок в другом месте снимка завершает подпись.
Двойной щелчок снова открывает её для ввода, **Escape** отменяет текущий ввод.
Просмотр закрывается, полка плавно сворачивается и остаётся скрытой на время редактирования.
**«Сохранить»** (⌘S) обновляет изображение на той же карточке, её миниатюру и файл
для перетаскивания, закрывает редактор и раскрывает полку с выделенной карточкой.
В разделе **«Скриншоты»** правки сразу записываются в исходный снимок в папке захвата
под тем же именем и в том же формате. Для разметки, сделанной в прежней версии Tray,
откройте карточку в редакторе и нажмите «Сохранить».
Если карточка была ниже видимой строки, полка прокручивается к ней.
При ошибке сохранения редактор остаётся открытым с правками.
⌘Z / ⇧⌘Z отменяют и повторяют правки; закрытие с несохранёнными
пометками предлагает сохранить их, отменить закрытие или не сохранять.

Редактор принимает однокадровые PNG, JPEG, HEIC и TIFF до 80 мегапикселей.
Редактор сохраняет исходное разрешение и учитывает ориентацию. В разделе «Файлы»
результат сохраняется на полке в формате PNG. После повторного открытия пометки являются
частью изображения. Отдельные редактируемые слои пока не хранятся.

Двойной щелчок открывает сохранённую копию. Правый щелчок предлагает открыть,
показать в Finder или убрать с полки. Кнопка «+» открывает выбор файлов.
При наведении на файл слева сверху появляется небольшой крестик в кружке.
Он убирает только этот файл с полки, даже если выбрано несколько файлов.
Во время перетаскивания крестик скрыт; оригинальный файл остаётся на месте.
Кнопки «+» и «…» находятся справа внизу. «…» позволяет выбрать всё и очистить
текущий раздел, а также открыть «Настройки скриншотов». На полке Escape сворачивает панель.
Внизу находятся переключатели «Файлы» и «Скриншоты» (камера со счётчиком).
Между разделами можно переключаться горизонтальным движением двумя пальцами
по трекпаду, когда указатель находится над раскрытой полкой. Направление
соответствует настройке прокрутки macOS: содержимое влево — к скриншотам,
вправо — обратно к файлам. Страницы следуют за пальцами, а после отпускания
плавно доходят до соседнего раздела или возвращаются обратно после короткого
движения. Новый жест может подхватить ещё движущуюся страницу. Сначала полка
определяет преобладающее направление и закрепляет его до конца контакта:
горизонтальное движение листает страницы, вертикальное прокручивает текущий
раздел. При включённом «Уменьшении движения» переход происходит без анимации.
Жесты во время перетаскивания
файлов не переключают разделы. Каждый раздел сохраняет своё выделение и прокрутку. Ручное добавление через
«+» и перетаскивание на полку направляют файлы в раздел «Файлы».
Полка также открывается из значка в строке меню. Там же выбирается экран
и доступна команда «Завершить Notch Tray».
Щелчок по чёлке удерживает полку открытой до щелчка снаружи или Escape.

Слева внизу — первая кнопка быстрых действий: папка с **⇧⌘G**.
Откройте Finder или стандартное окно открытия / сохранения файла в другом
приложении, раскройте полку и нажмите эту кнопку. Полка свернётся, а исходное
приложение получит ⌘⇧G и откроет системный ввод пути. Вставьте путь к папке
или файлу и подтвердите его. Содержимое буфера обмена кнопка не меняет.
В приложениях с собственными диалогами действие зависит от поддержки ⌘⇧G.

Для отправки сочетания macOS требует разрешение для Notch Tray в
«Системные настройки → Конфиденциальность и безопасность → Управление устройством
и доступ к данным» (в прежних версиях macOS — «Универсальный доступ»).
При первом нажатии без разрешения приложение предложит открыть эти настройки.
После включения вернитесь в нужное окно и нажмите кнопку повторно; если macOS
потребует перезапуск, закройте и откройте Notch Tray. Разрешение используется
для отправки команды по нажатию; чтения нажатий клавиатуры нет.
Это первая готовая команда; редактор произвольных сочетаний пока не добавлен.

Если доступ включён, но после обновления кнопка снова просит разрешение:

1. Завершите Notch Tray через его значок в строке меню.
2. В указанном разделе настроек выберите Notch Tray и удалите запись кнопкой «−».
3. Нажмите «+», добавьте `/Applications/Notch Tray.app` и включите доступ.
4. Откройте именно эту копию приложения, вернитесь в Finder и проверьте кнопку ⇧⌘G.

До версии 0.4.3 сборки подписывались ad-hoc: системная идентичность менялась
вместе с кодом. [Apple описывает это ограничение подписи](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements).
Начиная с 0.4.3 используется один локальный сертификат, поэтому идентичность
сохраняется между сборками. При переходе со старой подписи может понадобиться
однократно удалить прежнюю запись и выдать доступ новой копии по инструкции выше.
Повторное добавление не удаляет файлы полки. Перезагрузка Mac для смены записи
не требуется. Сохранение доступа после следующего обновления ещё нужно подтвердить.

Сертификат для сборки задаётся отпечатком в `signing-identity.txt` или переменной
`NOTCH_TRAY_SIGNING_IDENTITY`. Для собственной сборки выберите доступный
сертификат подписи кода в своей Связке ключей.
Закрытый ключ остаётся в Связке ключей. Сборка завершается ошибкой при отсутствии
сертификата и не переключается на ad-hoc. Для диагностики без загрузки хранилища:
`open -n "/Applications/Notch Tray.app" --args --permission-report /tmp/notch-tray-permissions.json`.
Отчёт содержит путь приложения и ответы macOS на проверки Accessibility и отправки событий;
режим не запрашивает разрешений и не отправляет клавиши.

В свёрнутом виде приложение полностью невидимо, независимо от количества
файлов: без значка, счётчика, полоски или выступающей подложки. Область
наведения совпадает с чёлкой и пропускает клики в системную строку меню.
Наведите курсор на чёлку — полка раскроется. При уходе курсора закрытие
начинается через 0,3 секунды. Повторное наведение плавно меняет направление
анимации. Сетка файлов сохраняет размер во время раскрытия. Настройка macOS
«Уменьшать движение» отключает движение панели.

Поддерживаются файлы, папки, несколько файлов, изображения PNG/TIFF из drag
pasteboard, а также file promises — файлы, которые исходное приложение
создаёт в момент перетаскивания. Принимающее приложение должно поддерживать
перетаскивание соответствующего типа файла.

## Скриншоты

Снимайте обычными клавишами macOS: **⇧⌘3** — весь экран, **⇧⌘4** — область,
**⇧⌘4, затем пробел** — окно. Tray автоматически добавит новые сохранённые
снимки в отдельный раздел. Полка не раскрывается сама и не забирает фокус.
Пустая камера показывается без счётчика; после добавления виден счётчик снимков.

Откройте **«…» → «Настройки скриншотов»** (то же меню доступно из значка
приложения в строке меню):

- **Автоматически добавлять новые скриншоты** — включить или приостановить приём.
- **Убирать после успешного перетаскивания** — переданные снимки исчезают с полки.
- **Выбрать папку…** — указать ту же папку, куда macOS сохраняет снимки.
- **Использовать папку macOS** — вернуться к автоматическому определению.
- **Показать папку в Finder** — открыть оригиналы.

Оба переключателя включены по умолчанию и сохраняются между запусками.
Фактическая папка указана в меню. Системное место сохранения меняется отдельно:
**⇧⌘5 → Параметры → Место сохранения**; по умолчанию это рабочий стол.
Tray определяет папку по настройкам macOS, но эти настройки не являются
стабильным публичным API. Если папка определена неверно или недоступна,
выберите её вручную через меню Tray. Смена системной папки проверяется
периодически и может отразиться с задержкой около 10 секунд.

При первом подключении папки и повторном включении приёма её старые файлы
пропускаются. Обычный перезапуск сохраняет историю: ещё не принятые новые
снимки могут добавиться, уже убранные не возвращаются. Распознавание использует
метаданные системного снимка, поэтому обычные картинки с похожим именем не
попадают в раздел. Снимки только в буфере обмена (с дополнительной Control)
и изображения без метаданных системного захвата автоматически не принимаются.

Успех перетаскивания означает, что приложение-получатель подтвердило операцию
копирования. Отмена или отклонённая передача оставляют карточки. При передаче
нескольких снимков подтверждение относится к сессии целиком: Tray не может
проверить последующую отправку сообщения, загрузку вложений или обработку
каждого файла внутри другого приложения. Обычные файлы остаются на полке.

Оригиналы скриншотов всегда остаются в исходной папке. Tray хранит отдельные
копии по той же схеме, что обычные файлы, и историю обработанных источников.
Начиная с 0.4.6 история использует постоянный UUID тома, чтобы
старые снимки не возвращались после перезагрузки Mac; прежний журнал переносится
автоматически. Если диск не предоставляет постоянный идентификатор, меню попросит
выбрать другую папку для автоматического приёма. Уже появившиеся лишние карточки
исправление автоматически не очищает. Полка не исключает своё
раскрытое окно из системного захвата: перед снимком сверните её, если она не
должна попасть в кадр.

## Что происходит с файлами

- Полка хранит отдельные копии. Оригиналы не перемещаются и не удаляются.
- При выдаче доступна операция копирования. Обычные файлы остаются на полке.
  Для скриншотов действует настройка удаления после успешной передачи.
  Отмена перетаскивания сохраняет все карточки.
- Активные файлы сохраняются после перезапуска без автоматического срока удаления.
- При сохранении разметки скриншота Tray заменяет исходный файл и обновляет копию
  на полке. Если исходник недоступен, правки остаются в редакторе для повторной попытки.
  Для изображений из раздела «Файлы» редактируется только копия на полке.
  Ранее выданные копии доступны ещё 24 часа после удаления карточки.
- Убранные с полки копии хранятся ещё 24 часа, чтобы принимающее приложение могло
  закончить чтение. После этого срока очистка проверяется при запуске, примерно
  раз в минуту и после пробуждения Mac. Файлы в просмотре и редакторе защищены;
  на время перетаскивания очистка откладывается. Использование сторонними
  приложениями не отслеживается — для них остаётся запас 24 часа.
- Хранилище: `~/Library/Application Support/NotchTray/`.
- При первом сохранении разметки манифест формата 1 переходит в формат 2. Предыдущий манифест
  сохраняется как `shelf-before-image-editing.json`. Сборки до этой функции не читают
  формат 2; простая замена приложения старой сборкой не является откатом хранилища.
- Исправление учёта скриншотов в 0.4.6 переводит манифест в формат 3 при
  первой записи постоянных идентификаторов. Предыдущий файл сохраняется как
  `shelf-before-screenshot-identity.json`; исходная история и разметка сохраняются.
  Сборки до 0.4.5 включительно не читают формат 3. Редактирование изображений
  сохраняет этот формат.
- Большие файлы и папки требуют места под копии; интерфейс показывает процесс добавления.
- Полка использует один выбранный экран. По умолчанию — экран с аппаратной чёлкой.
  На мониторе без чёлки показывается небольшая панель у верхнего края.
- Функций музыки, календаря, AirDrop и облачной синхронизации нет.

## Проверка этой сборки

В 0.4.11 на временных файлах проверены замена PNG, JPEG, HEIC и TIFF под исходным
именем, сохранение после переименования снимка и восстановление после прерванной записи.

В 0.4.10 на изолированных данных проверены управление фигурами при другом
активном инструменте, изменение за боковые и угловые точки, отмена по жестам,
сохранение и видимость панели при минимальной ширине окна.

В 0.4.9 полный `bash test.sh` прошёл на изолированных данных. Отдельно для
бинарника с минимумом macOS 14 проверены жесты, экспорт PNG, отмена и публикация
изменений на той же карточке. Запуск на самих macOS 14 и 15 ещё предстоит проверить.

В 0.4.7 полный `bash test.sh` прошёл на изолированных данных, включая 57 проверок
Quick Look и 74 проверки редактирования. Проверены клавиатурный фокус, переходы
между файлами и возврат к последней просмотренной карточке.

Для 0.4.6 полный `bash test.sh` прошёл на изолированных данных,
включая 44 новые проверки смены номера диска, миграции истории, резервной копии,
повторного запуска, переименования, очистки и восстановления после ошибки записи.
Физическая перезагрузка Mac с новой сборкой ещё не проверена.

В версии 0.4.5 полный `bash test.sh` прошёл на изолированных данных: 24 проверки
просмотра и 74 проверки редактора/сохранения, включая большие окна, возврат
фокуса, сворачивание полки, ошибки записи, отмену закрытия, завершение приложения

В версии 0.4.2 переключение разделов стало интерактивным: две живые страницы
двигаются вслед за пальцами, затем плавно завершают переход с учётом расстояния
и скорости отпускания. Начальные события буферизуются до определения оси,
чтобы небольшое дрожание по вертикали не перехватывало горизонтальный жест.
Вертикальный поток вместе с инерцией передаётся стандартному NSScrollView.
Проверки включают выбор оси, движение и завершение страниц, смену направления,
повторный захват анимации, сохранение выделения и прокрутки. События тестов
создаются в памяти и не отправляются в систему; физическое ощущение жеста
пользователь проверяет сам.

В версии 0.4.0 добавлены раздел скриншотов, приём системных файлов, меню

Полный `bash test.sh` проходит: прежние проверки хранения, движения,

Проверки AppKit требуют запуска с доступом к графической сессии macOS.

При первом изменении старого хранилища исходный манифест сохраняется как

## Сборка из исходников

Нужны актуальные Command Line Tools с Swift или Xcode. Выпуск 0.4.12 собран с SDK macOS 27.2.
Команда `security find-identity -v -p codesigning` показывает доступные сертификаты.
В Terminal из этой папки укажите отпечаток своего сертификата:

```sh
NOTCH_TRAY_SIGNING_IDENTITY="ОТПЕЧАТОК_СЕРТИФИКАТА" bash build.sh
bash test.sh
```

Приложение создаётся рядом с папкой исходников. Архитектура — архитектура
текущего Mac (`arm64` или `x86_64`), минимальная система — macOS 14.
Сборка использует AppKit, QuartzCore, QuickLookUI, QuickLookThumbnailing, ImageIO,
CoreGraphics, CoreText, ApplicationServices и Foundation.
Кэш компилятора и тесты лежат в `.build/`.

Для изолированного тестового хранилища можно запустить исполняемый файл с переменной
`NOTCH_TRAY_DATA_DIR` и абсолютным путём. Параметр `--show` раскрывает полку при запуске.
