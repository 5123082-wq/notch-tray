# Разработка Notch Tray

## Сборка из исходников

Нужны актуальные Command Line Tools с Swift или Xcode. Выпуск 0.4.12 собран с SDK macOS 27.2.
Команда `security find-identity -v -p codesigning` показывает доступные сертификаты.
В Terminal из корня репозитория укажите отпечаток своего сертификата:

```sh
NOTCH_TRAY_SIGNING_IDENTITY="ОТПЕЧАТОК_СЕРТИФИКАТА" bash build.sh
bash test.sh
```

Приложение создаётся рядом с папкой исходников. Архитектура — архитектура
текущего Mac (`arm64` или `x86_64`), минимальная система — macOS 14.
Сборка использует AppKit, QuartzCore, QuickLookUI, QuickLookThumbnailing, ImageIO,
CoreGraphics, CoreText, ApplicationServices и Foundation.
Кэш компилятора и тесты лежат в `.build/`.

Для изолированного тестового хранилища можно запустить исполняемый файл с переменной
`NOTCH_TRAY_DATA_DIR` и абсолютным путём. Параметр `--show` раскрывает полку при запуске.

## Образ для скачивания

Для DMG используйте подписанное приложение того же выпуска. На Mac с установленным [dmgbuild](https://github.com/dmgbuild/dmgbuild) выполните из корня репозитория:

```sh
dmgbuild -s Tools/dmg-settings.py -D 'app=../Notch Tray.app' 'Notch Tray' Notch-Tray-arm64.dmg
hdiutil verify Notch-Tray-arm64.dmg
```

Смонтируйте результат только для чтения и проверьте подпись приложения. В корне образа должны быть видны Notch Tray и ссылка Applications, ведущая в `/Applications`. На странице выпуска GitHub используйте имя `Notch-Tray-arm64.dmg` для сборок Apple Silicon. Кнопка сайта подхватывает этот файл из последнего стабильного выпуска.

## Подпись и диагностика разрешений

До версии 0.4.3 сборки подписывались ad-hoc: системная идентичность менялась
вместе с кодом. [Apple описывает это ограничение подписи](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements).
Начиная с 0.4.3 используется один локальный сертификат, поэтому идентичность
сохраняется между сборками. При переходе со старой подписи может понадобиться
однократно удалить прежнюю запись и выдать доступ новой копии по [инструкции в руководстве пользователя](guide.ru.md).
Повторное добавление не удаляет файлы полки. Перезагрузка Mac для смены записи
не требуется. Сохранение доступа после следующего обновления ещё нужно подтвердить.

Сертификат для сборки задаётся отпечатком в `signing-identity.txt` или переменной
`NOTCH_TRAY_SIGNING_IDENTITY`. Для собственной сборки выберите доступный
сертификат подписи кода в своей Связке ключей.
Закрытый ключ остаётся в Связке ключей. Сборка завершается ошибкой при отсутствии
сертификата и не переключается на ad-hoc. Для диагностики без загрузки хранилища:
`open -n "/Applications/Notch Tray.app" --args --permission-report /tmp/notch-tray-permissions.json`.
Отчёт содержит путь приложения и ответы macOS на проверки Accessibility и отправки событий;
режим не запрашивает разрешений и не отправляет клавиши.

## История проверок

В 0.4.11 на временных файлах проверены замена PNG, JPEG, HEIC и TIFF под исходным
именем, сохранение после переименования снимка и восстановление после прерванной записи.

В 0.4.10 на изолированных данных проверены управление фигурами при другом
активном инструменте, изменение за боковые и угловые точки, отмена по жестам,
сохранение и видимость панели при минимальной ширине окна.

В 0.4.9 полный `bash test.sh` прошёл на изолированных данных. Отдельно для
бинарника с минимумом macOS 14 проверены жесты, экспорт PNG, отмена и публикация
изменений на той же карточке. Запуск на самих macOS 14 и 15 ещё предстоит проверить.

В 0.4.7 полный `bash test.sh` прошёл на изолированных данных, включая 57 проверок
Quick Look и 74 проверки редактирования. Проверены клавиатурный фокус, переходы
между файлами и возврат к последней просмотренной карточке.

Для 0.4.6 полный `bash test.sh` прошёл на изолированных данных,
включая 44 новые проверки смены номера диска, миграции истории, резервной копии,
повторного запуска, переименования, очистки и восстановления после ошибки записи.
Физическая перезагрузка Mac с новой сборкой ещё не проверена.

В версии 0.4.5 полный `bash test.sh` прошёл на изолированных данных: 24 проверки
просмотра и 74 проверки редактора/сохранения, включая большие окна, возврат
фокуса, сворачивание полки, ошибки записи, отмену закрытия, завершение приложения
и прокрутку к сохранённой карточке. Физические клавиши и ощущение переходов
пользователь проверяет сам.

В версии 0.4.2 переключение разделов стало интерактивным: две живые страницы
двигаются вслед за пальцами, затем плавно завершают переход с учётом расстояния
и скорости отпускания. Начальные события буферизуются до определения оси,
чтобы небольшое дрожание по вертикали не перехватывало горизонтальный жест.
Вертикальный поток вместе с инерцией передаётся стандартному NSScrollView.
Проверки включают выбор оси, движение и завершение страниц, смену направления,
повторный захват анимации, сохранение выделения и прокрутки. События тестов
создаются в памяти и не отправляются в систему; физическое ощущение жеста
пользователь проверяет сам.

В версии 0.4.0 добавлены раздел скриншотов, приём системных файлов, меню
настроек, удаление после передачи и постоянная защита от повторного импорта.
Полный `bash test.sh` проходит: прежние проверки хранения, движения,
горячей команды, раскрытия, приёма файлов и наведения, а также 22 проверки
приёма/хранения скриншотов, 41 проверка контроллера/меню и 23 проверки
навигации и состояния интерфейса. Все данные тестов изолированы.
Проверки AppKit требуют запуска с доступом к графической сессии macOS.

При первом изменении старого хранилища исходный манифест сохраняется как
`shelf-v0.3-backup.json`; пути существующих копий не меняются. Новый манифест
содержит категории и историю источников, поэтому старая версия приложения
для отката требует восстановления прежнего манифеста.


В версии 0.3.2 исправлено залипание крестиков на нескольких файлах.
Полка определяет единственную карточку под курсором; отдельные карточки
больше не хранят независимые состояния наведения. Крестик обновляется при
движении курсора, прокрутке и изменении раскладки, скрывается при сворачивании
и перетаскивании. Проверки проходят переходы между десятью файлами,
прокрутку, повторное раскрытие, устаревшие события и удаление.

В версии 0.3.1 добавлена кнопка удаления отдельного файла при наведении.
Проверка на отдельном временном хранилище охватывает удаление одного файла
при множественном выделении, сохранность остальных файлов и оригиналов,
появление/скрытие кнопки и приоритет перетаскивания над кнопкой.

В версии 0.3.0 убраны заголовок и постоянные подписи; файлы подняты на 35 пунктов,
высота раскрытой полки уменьшена на 74 пункта. Кнопки собраны в компактную
нижнюю панель. Дополнительные ряды файлов доступны прокруткой.
Ошибки и ход добавления показываются в нижней строке; полный текст ошибки —
в подсказке при наведении. Меню остаётся открытым при уходе курсора с полки.

Для ⌘⇧G добавлены 12 автоматизированных проверок: адресат, возврат фокуса,
переключение и закрытие приложения, повторное использование PID, отказ или
отзыв разрешения, ограниченное ожидание активации и события нажатия/отпускания.
Проверки используют подставные приложения и не отправляют реальные клавиши.
`Tools/ShortcutTarget.swift` — отдельное тестовое приложение с нативными
диалогами открытия и сохранения для ручной проверки; оно не записывает
выбранные пользователем файлы.

В версии 0.2.1 исправлена готовность области сброса во время раскрытия:
полка принимает перетаскивание уже с первого кадра анимации, а окно в области
чёлки подготавливается ещё при движении файла к нему. Декоративная картинка
больше не зарегистрирована как отдельный получатель PDF/изображений/файлов.
Во время входящего перетаскивания вся полка использует один обработчик сброса;
после завершения возвращаются обычные клики по кнопкам и перетаскивание миниатюр.
В покое свёрнутая полка по-прежнему пропускает клики в строку меню.

Добавлены 25 нативных регрессионных проверок: первый сброс PDF, побайтовая
сохранность копии и оригинала, область сброса на разных стадиях раскрытия,
пустая и заполненная полка, отмена, несколько файлов и папка, недоступный файл,
неподдерживаемый текст и запрет повторного приёма собственного исходящего drag.
Тесты вызывают обработчики AppKit с тестовым NSDraggingInfo и отдельным
pasteboard; это не автоматизация реального перетаскивания из Finder.
Ошибка области сброса воспроизведена на 0.2.0: сразу после expand() hitTest
возвращал nil. Причина не зависит от расширения файла или папки-источника.

20 автоматизированных проверок пройдены. Проверены сохранность оригиналов,
копирование папок, одинаковые и Unicode-имена, перезапуск, ошибки импорта и
записи, отложенная очистка и передача нескольких file URL через pasteboard.
Приложение запущено на этом Mac; добавление через диалог и восстановление
полки после перезапуска проверены в интерфейсе. Пользователь также подтвердил,
что выдача файлов из чёлки в другое приложение работает.

Полная совместимость со всеми приложениями, iCloud-файлами без локальной
копии, всеми источниками file promises и конфигурациями нескольких мониторов
пока не проверена. Это первая рабочая версия для локального использования.

В версии 0.2.0 дополнительно проверены непрерывный разворот анимации,
одинаковый темп на 30/60/120 Гц и нативная отрисовка пустой и заполненной
полки: в свёрнутом состоянии число видимых пикселей равно нулю.
